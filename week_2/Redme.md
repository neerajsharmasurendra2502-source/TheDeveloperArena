# Student Grade Calculator

This is a simple Python program that takes a student's
name and marks and calculates their grade.

## Grading Logic

- A: 90-100
- B: 80-89
- C: 70-79
- D: 60-69
- F: 0-59

## How to Run

1. Install Python.
2. Open the project in VS Code.
3. Run:

```bash
python grade_calculator.py
